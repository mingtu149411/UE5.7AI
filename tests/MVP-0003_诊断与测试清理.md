# MVP-0003：项目诊断与测试清理

- **测试项目：** `D:\xuexishiyong\ue--myproject\AI插件测试项目`
- **引擎：** UE 5.7.4
- **插件：** `UE5AIMcp` r5

## 诊断测试

请求 `GET /ue5ai/diagnostics` 成功返回：

- `project = AI插件测试项目`
- `has_world = true`
- `is_pie = false`
- `write_tools_enabled = false`

## 生命周期清理测试

1. 启动隐藏测试编辑器实例。
2. 请求 `POST /ue5ai/test-shutdown`。
3. 收到 `status = exit requested`。
4. 5 秒后确认该 UE 进程不存在。

结论：插件可在测试结束后自行退出测试编辑器并释放 DLL。已删除被 r5 替代的临时构建目录 `build/UE5AIMcp-r3` 与 `build/UE5AIMcp-r4`。
