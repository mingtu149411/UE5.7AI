# UE5 AI MCP

> **项目作者：南京大学24届沈逸文**
> UE 5.7 编辑器自动化插件｜版本 `0.4.0-showcase-levels`

UE5 AI MCP 是在本机 Unreal Editor 与支持 MCP 的 AI 客户端之间建立受控连接的编辑器插件。它通过 `127.0.0.1:8175` 提供经过白名单约束的读取、创建、编辑、PIE、保存与诊断能力，并由 `bridge/ue5ai_mcp_bridge.py` 提供 MCP stdio 适配。

## 快速开始

1. 用 UE 5.7 打开目标项目并启用 `UE5 AI MCP`；
2. 确认健康检查路由 `http://127.0.0.1:8175/ue5ai/health` 可访问；
3. 在 MCP 客户端中以 Python 启动 `bridge/ue5ai_mcp_bridge.py`；
4. 先读取工具清单和项目快照，再执行任何写入动作；
5. 写入后保存脏包并使用资产/PIE 状态回读验证。

插件是 **Editor** 模块，只绑定本机回环地址。它不应直接暴露到局域网或互联网。
